Method

How it works

The scanner reads your world's save files directly, so every number comes from data actually stored in the world. Nothing is estimated and nothing leaves your device.

01Open the archive

Your ZIP is opened in the browser. The scanner looks for region files named like r.0.0.mca in the Overworld region folder, the Nether DIM-1, the End DIM1 and the newer dimensions layout.

02Read the chunks

Each region file holds up to 1,024 chunks. A table at the start of the file gives every chunk's position, size and compression type, and each chunk is decompressed in turn.

03Parse the data

Chunks are stored as NBT, Minecraft's binary save format. A built-in parser decodes it and pulls out the block entities, the blocks that store data such as chests and barrels.

04Count the contents

For chests, trapped chests, barrels, hoppers, droppers, dispensers and shulker boxes, every item stack is added up. A shulker box carries its contents inside the item itself, so those are opened and counted too, however deeply nested.

Not counted: player inventories, ender chests, dropped items, item frames and storage minecarts. Results depend on the world format and the files present in the ZIP.
